# Planeta Fitness — Frontend

Frontend estático construido con HTML, CSS y módulos JavaScript nativos.

## Despliegue

GitHub Actions valida el código y la seguridad, y luego publica el sitio en GitHub Pages cuando hay un push a `main`. También se puede iniciar manualmente desde la pestaña Actions.

Sitio: https://ariel-as.github.io/FRONTEND-DE-PRUEBA/

## API

La URL base de la API está en `models/config.js` y actualmente apunta a `https://planeta-fitness-api.onrender.com/api/v1`, para que las funciones conectadas a la API trabajen desde el sitio publicado. Para desarrollo local puede ajustarse temporalmente a `http://localhost:5050/api/v1`.
